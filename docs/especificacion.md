|   | Caso de uso |
| --- | --- |
| Nombre de caso de uso | Gestionar respuesta del usuario |   
| Breve descripción | El sistema capta la respuesta del usuario a una pregunta y la procesa |
| Flujo básico | El sistema presenta la pregunta y espera la respuesta del usuario. El usuario responde "Si" o "No" y el sistema capta la respuesta. |
| Flujos alternativos | El usuario ingresa respuestas no coherentes o imposibles que sucedan, en tal caso el sistema debera informar que el diagnostico no es preciso y se le pide al usuario que lo intente nuevamente. |
| Requisitos especiales | Ninguno |
| Condiciones previas | El sistema presenta el modulo de diagnostico |
| Condiciones posteriores | El sistema verifica si ha encontrado un resultado en la base de conocimiento y presenta el diagnostico, si no, sigue preguntando hasta llegar a un diagnostico. |
| Puntos de extensión | Ninguno |
